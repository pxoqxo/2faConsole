# 🖥️ 2faConsole

**2faConsole** is a lightweight ⚡, cross-platform 🖥️ two-factor authentication **(2FA)** console application built with **C#** 💖 **.NET**. Powered by 🔋 the dependency-free **Pxoqxo.Otp2fa** library, it delivers secure 🔒, terminal-based OTP management 🧰 without the bloat.

🛡️ **100% Free & Open-Source Software (FOSS)**

### 🚀 Key Features

*   **RFC Compliant:** Full native support for **TOTP** *(📄 RFC 6238)* and **HOTP** *(📄 RFC 4226)*.
*   **Zero Bloat:** Built on a completely dependency-free architecture 🔥.
*   **Cross-Platform:** Runs seamlessly ⚡ on **Windows**, **macOS**, and **Linux** terminals.

## 🛠️ Prerequisites
- **2faConsole (em1.0)**
  - .NET 8 SDK (or newer)
  - Pxoqxo.ConsolePlus (em1.0)
  - Pxoqxo.Ext.Core (em1.0)
  - Pxoqxo.Otp2fa (em1.0)
  - Pxoqxo.Quick (em1.0)
